# Student Performance Analysis using Python

## Project Overview
This is a beginner-level Data Science project developed using Python. The project analyses student academic performance using Pandas and Matplotlib.

## Objectives
- Analyse student marks.
- Calculate average marks.
- Identify highest and lowest scores.
- Compare subject-wise performance.
- Analyse the relationship between study hours and marks.
- Rank students based on their average marks.

## Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib

## Project Features
1. Student dataset creation.
2. Data analysis using Pandas.
3. Subject-wise average calculation.
4. Data visualization using charts.
5. Correlation analysis.
6. Student performance ranking.
7. Exporting analysed data into CSV format.

## Project Files
- `students_performance_analysis.ipynb` – Python source code.
- `student_performance_analysis.csv` – Analysed student dataset.
